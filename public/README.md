## Rules for new assets

1. Add assets to the relevant feature folder, not the public root.
2. Use lowercase kebab-case filenames without spaces.
3. Keep provider logos under `service-providers/<category>/`.
4. Use descriptive alt text wherever the asset is rendered.
5. Do not rename existing assets without updating every reference.
